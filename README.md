# Тренажёр ноутбука для детей 🖥️

Интерактивный сайт, который показывает ребёнку **куда нажимать** на ноутбуке (Windows).

- Русский + Казахский
- Кликай по кнопкам и сразу получаешь объяснение
- Полностью бесплатно

## Как открыть прямо сейчас

1. Открой этот файл: [index.html](https://github.com/superyaroslav8-arch/kids-laptop-trainer/blob/main/index.html)
2. Нажми кнопку **Raw** (вверху справа)
3. Или скачай файл и открой в браузере (двойной клик)

## GitHub Pages (постоянная ссылка)

После включения Pages сайт будет здесь:
**https://superyaroslav8-arch.github.io/kids-laptop-trainer/**

Чтобы включить:
1. Зайди в Settings → Pages
2. Source → Deploy from a branch → main → / (root) → Save

Или подожди несколько минут — workflow уже запущен.

Сделано для детей. Учитесь с удовольствием!
